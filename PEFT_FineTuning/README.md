
# PEFT_FineTuning


**Floder:** *Parameter-Efficient Fine-Tuning (PEFT) Experiments*  

**Description:**  
Practical experiments applying **PEFT methods** for adapting large language models efficiently using fewer parameters.  
Includes tasks like summarization, NER, and dialogue fine-tuning.

**Projects Include:**
- LoRA fine-tuning on T5 and FLAN models (`LoRA_Finetuning.ipynb`)  
- ClinicalBERT fine-tuning for NER (`FineTuning_ClinicalBert_NER.ipynb`)  
- Evaluation using ROUGE metrics (ROUGE-1, ROUGE-2, ROUGE-L, ROUGE-Lsum)

- Hugging Face Transformers, Datasets, PEFT
